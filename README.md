# 🐕 Dog Walk Log

A mobile-first web app for tracking daily dog walks.

> [!NOTE]
> Try it now!: [marfullsen.github.io/dog-walk-log/](https://marfullsen.github.io/dog-walk-log/)

## Features

- **Swipe to log** — Tactile slider to confirm each walk
- **Walk history** — Reverse-chronological list with stats (week, streak, total)
- **Calendar view** — Monthly grid highlighting walked days
- **Customizable profile** — Name, Nickname, breed, and 3 avatar choices
- **Localization** — Toggle between English and Japanese
- **Themes** — Warm Sand, Cool Breeze, Autumn Leaf and many other color palettes
- **Persistent storage** — All data saved to `localStorage`

## Quick Start

Open the live version here: [marfullsen.github.io/dog-walk-log/](https://marfullsen.github.io/dog-walk-log/)

To run it on localhost you can also try this:

1. Save the HTML file to your computer, run Five Server
2. Open it in any browser (Chrome, Safari, Firefox, Edge)
3. Start logging walks!

> **Tip:** On mobile, use "Add to Home Screen" for a native app feel.

## Data

All walks and preferences are stored locally in your browser via `localStorage`.

## Tech Stack

- Pure HTML5 / CSS3 / Vanilla JavaScript
